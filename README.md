# Catálogo de Productos

Este proyecto es un catálogo básico desarrollado para organizar y mostrar artículos de manera sencilla.

## Características
* Listado de productos con nombre y precio.
* Estructura ordenada en la carpeta `src`.
* Fácil de actualizar y mantener.

## Cómo usar
1. Clona este repositorio en tu computadora.
2. Abre los archivos de la carpeta `src` en tu editor de código.
3. Ejecuta el archivo principal para ver el catálogo.
